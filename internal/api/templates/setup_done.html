The GitHub App {{.Body.Name}} is ready

These credentials are shown once. The server has not stored them anywhere; if you lose them, generate a new private key and client secret in the App's settings on GitHub.

1. Store the credentials

Put these values in your secret store and pass them to the server as environment variables:

{{range .Body.Env}}{{.Name}}={{.Value}}
{{end}}

GITHUB_APP_PRIVATE_KEY is the App's private key. Store the whole PEM block, BEGIN and END lines included, as one secret in AWS Secrets Manager (or your platform's equivalent) and hand it to the server through the task's secrets, never in the image. The server also accepts the PEM with its line breaks written as \n.

{{.Body.PrivateKey}}

2. Restart the server

Restart the server with these variables next to STACKORDER_BASE_URL, DATABASE_URL and STACKORDER_SESSION_KEY. Until it has them it stays in setup mode.

3. Install the App

Install {{.Body.Name}}

Install it on the organisation and select the repositories that hold stacks, the repositories that hold shared git modules, and those named by cross-repository depends_on entries.

4. Give the App a logo

Until the App has a logo, GitHub shows the avatar of the account that owns it on every comment and check the App posts. GitHub offers no API for the logo, so upload it by hand: save the Stackorder logo, open the App's settings, and choose Upload a logo under Display information.
